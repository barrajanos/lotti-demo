# Lottie Animáció Hanggal 🎬🎵

Interaktív webalkalmazás Lottie animációval és szinkronizált hanggal, kétnyelvű támogatással (magyar/angol).

## ✨ Funkciók

- **Lottie animáció**: Gyönyörű vektoros animáció
- **Szinkronizált hang**: Az animáció tökéletesen szinkronizálva van a narációval
- **Kétnyelvű**: Magyar és angol nyelvű támogatás
- **Háttérzene**: Kellemes háttérzene fade-in/fade-out effektekkel
- **Reszponzív**: Mobil és desktop eszközökön is működik
- **Modern UI**: Elegáns, minimalista dizájn

## 🚀 Használat

1. Klónozd a repository-t:
```bash
git clone [repository-url]
cd "Lotti trr"
```

2. Indítsd el a fejlesztői szervert:
```bash
python3 -m http.server 8000
```

3. Nyisd meg a böngészőben: `http://localhost:8000`

## 🎛️ Vezérlés

- **Play/Pause**: Animáció és hang szüneteltetése/folytatása
- **Mute**: Hang némítása/visszakapcsolása
- **Nyelvváltó**: HU/EN kapcsoló a jobb felső sarokban
- **Replay**: Újra lejátszás gomb az animáció végén

## 🛠️ Technológiák

- **HTML5** + **CSS3**: Modern web szabványok
- **JavaScript**: Interaktivitás és vezérlés
- **Lottie Web**: Vektoros animációk
- **Web Audio API**: Hang szinkronizáció

## 📱 Kompatibilitás

- Chrome, Firefox, Safari, Edge
- Mobil és tablet eszközök
- Reszponzív dizájn
